# Запуск бота учёта расходов

Всё делается через сайты, программы устанавливать не нужно. Ключи и токены никому не присылайте, в том числе мне в чат: их вводите только в настройках Cloudflare.

## 1. Telegram-бот
1. В Telegram откройте @BotFather и отправьте `/newbot`.
2. Придумайте имя и username (должен заканчиваться на `bot`).
3. Сохраните выданный **токен** (длинная строка с двоеточием).

## 2. Ключ API модели
1. Зайдите на console.anthropic.com, создайте аккаунт и пополните баланс на несколько долларов. Этого хватит надолго.
2. В разделе API Keys создайте ключ и сохраните его.
3. Регистрация и оплата зависят от вашей страны: если чего-то не принимает, нужен другой способ оплаты или регион.

## 3. Таблица в Google Sheets
1. Откройте Google Drive, загрузите `Book_обновленный_бюджет.xlsx`, откройте его и выберите «Файл» → «Сохранить как Google Таблицу».
2. Опционально, но советую: сведите старые категории через «Правка» → «Найти и заменить» в колонке «Категория» листа Finance (Кафе, Кафе/обеды, Кафе/рестораны, Рестораны → Кафе и рестораны; Транспорт (такси) → Такси; WB, Wildberries → Маркетплейсы; Супермаркеты → Продукты; Услуги банка, Банковские комиссии → Комиссии банка). Ставьте «Искать в: этот лист» и «Точное совпадение с содержимым ячейки». Колонку «Учет в расходах» и Dashboard это не нарушит, если Dashboard считается формулами по названиям категорий. Перед заменой сделайте копию таблицы.
3. Создайте новый лист с названием **Правила** (именно так). Скопируйте в колонку A строки из файла `rules.txt`: каждая строка файла — одна ячейка.
4. Из адреса таблицы скопируйте **ID**: это часть между `/d/` и `/edit`.

## 4. Доступ бота к таблице (сервисный аккаунт)
1. Откройте console.cloud.google.com и создайте проект.
2. В «APIs & Services» → «Library» найдите **Google Sheets API** и включите.
3. «IAM & Admin» → «Service Accounts» → «Create service account», любое имя.
4. Откройте созданный аккаунт → «Keys» → «Add key» → «Create new key» → JSON. Скачается файл, он понадобится целиком.
5. Скопируйте email сервисного аккаунта (вида `...@...iam.gserviceaccount.com`), откройте свою таблицу → «Настройки доступа» и добавьте этот email с правом **Редактор**.

## 5. Cloudflare Workers
Код лежит в этом репозитории, копировать его вручную не нужно.
1. Зарегистрируйтесь на cloudflare.com и откройте «Workers & Pages» → «Create» → «Import a repository» (подключение к Git).
2. Разрешите Cloudflare доступ к GitHub и выберите репозиторий `expense-bot`. Имя воркера оставьте `expense-bot`, команду сборки оставьте пустой, команда деплоя — `npx wrangler deploy` (если она подставлена сама, ничего не меняйте).
3. Запустите деплой. Дальше при каждом обновлении кода в репозитории Cloudflare выкладывает новую версию сам.
4. Запомните адрес воркера, он выглядит как `https://expense-bot.аккаунт.workers.dev`.

## 6. Настройки воркера
«Settings» → «Variables and Secrets» → добавьте как **Secret**:

| Имя | Значение |
|---|---|
| TELEGRAM_TOKEN | токен бота из шага 1 |
| ANTHROPIC_API_KEY | ключ из шага 2 |
| GOOGLE_SERVICE_ACCOUNT_JSON | весь текст JSON-файла из шага 4 |
| SPREADSHEET_ID | ID таблицы из шага 3 |
| WEBHOOK_SECRET | любая строка из латиницы, цифр, `_` и `-` (например, 24 случайных символа) |

Необязательно, как **Text**: `MODEL` (по умолчанию `claude-sonnet-5-5`; `claude-haiku-5-5` дешевле), `TZ_OFFSET_HOURS` (по умолчанию 3, это Москва).

## 7. Память диалога (по желанию, бесплатно)
Нужна, чтобы работали уточнения вроде «нет, это был подарок».
1. «Storage & Databases» → «KV» → «Create» → имя `memory`. Скопируйте **ID** хранилища.
2. В файле `wrangler.toml` в репозитории уберите решётки в трёх строках `[[kv_namespaces]]`, вставьте ID вместо `ВСТАВЬТЕ_ID_ХРАНИЛИЩА` и сохраните. Cloudflare сам задеплоит изменение. Если не хочется править файл, просто скажите мне ID, и я внесу изменение.

## 8. Подключение бота к воркеру
Откройте в браузере (подставьте свои значения без скобок):

`https://api.telegram.org/bot<TELEGRAM_TOKEN>/setWebhook?url=<адрес воркера>/webhook&secret_token=<WEBHOOK_SECRET>`

Должно прийти `"ok":true`.

## 9. Закрываем бота от посторонних
1. Напишите боту любое сообщение. Он ответит вашим Telegram ID.
2. Добавьте ID в воркер как **Secret** `ALLOWED_USER_ID` и нажмите «Deploy».
3. Проверьте: напишите «кофе 350». Бот должен ответить, что записал, и в листе Finance появится строка.

## Если что-то не работает
- Бот молчит: проверьте шаг 8 (ответ `ok:true`) и «Logs» воркера.
- Ошибка про Google Sheets 403 или 404: таблица не открыта для email сервисного аккаунта или неверный SPREADSHEET_ID.
- Ошибка «Exceeded CPU» в логах: на бесплатном плане у воркера мало процессорного времени на запрос. Напишите мне текст ошибки, я упрощу код. Крайний случай — платный план Workers.
- Очистить память диалога: команда `/reset`.

Dashboard остаётся таким, как был: отчёты теперь удобнее просить у бота («отчёт за октябрь по категориям»).
